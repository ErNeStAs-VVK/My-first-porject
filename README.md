**Studentų balų skaičiavimo programa**

Ši programa leidžia:

- Įvesti studentų vardus, pavardes, namų darbų rezultatus ir egzamino balą.
- Automatiškai suskaičiuoti galutinį pažymį pagal vidurkį arba medianą.
- Duomenis įvesti keliais būdais:
 
2. Įvesti ranka per klaviatūrą.
3. Sugeneruoti atsitiktinius studentus.
4. Nuskaityti studentų sąrašą iš failo kursiokai.txt.
